# Khabar Ghor - Local Food Delivery Platform

## Project Structure

```
├── js/              # All JavaScript files
├── css/             # All stylesheets
├── assets/          # Static assets
│   ├── images/      # Product & restaurant images
│   ├── icons/       # UI icons
│   └── logo/        # Logo files
├── index.html       # Home page
├── login.html       # Login/Register
└── ...(other HTML files)
```

## Getting Started

1. Add Firebase config to `js/firebase-config.js`
2. Add all JavaScript files to `js/` folder
3. Add all CSS files to `css/` folder
4. Add images/icons/logos to `assets/` subfolders
5. Update HTML script/link tags to point to new paths
